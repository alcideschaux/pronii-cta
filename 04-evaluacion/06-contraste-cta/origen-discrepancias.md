# Origen de las discrepancias (análisis de expediente)

Fecha: 29 ago 2026.

Premisa tuya: si CTA y pares aplican el **mismo instrumento** con criterios claros, no debería haber discrepancias de veredicto. Cuando las hay, el origen es uno de estos:

| Código de origen | Significado | Qué hacer |
|---|---|---|
| `A` | **Tu interpretación** del reglamento se apartó del texto claro (o del CCH ya zanjado) | Corregir el borrador; no hace falta CCH |
| `B` | **Interpretación del par** se apartó del texto claro / CCH | Mantener tu veredicto y fundamentar con RES+CCH |
| `C` | **Ambigüedad real** del instrumento (CCH aún no zanjó) | Elevar a CCH con pregunta precisa |
| `D` | **Hechos / evidencia** del expediente (¿está o no el anexo?) | Resolver en SPI/ZIP antes de votar |
| `E` | **Subaplicación del umbral** (p. ej. no sugeriste ascenso a II pudiendo hacerlo) | Releer checklist del nivel superior y ajustar si corresponde |

Confirmado por vos: en permanencia la CTA **puede sugerir reclasificación / ascenso**.

Fuentes: notas, dictámenes, extractos pares, SPI descomprimido, RES-376 Salud, correos CCH.

## Mapa mental: ¿por qué hay discrepancias si el instrumento es el mismo?

```
¿El texto + CCH ya fijaron el punto?
        │
        ├─ SÍ, y el expediente es claro
        │     ├─ Tú te apartaste  → origen A o E  → corregir dictamen
        │     └─ El par se apartó → origen B      → mantener + citar RES/CCH
        │
        ├─ SÍ el texto, pero el expediente es dudoso
        │     → origen D → primero hechos (anexos)
        │
        └─ NO (afinidad Metodología↔clínica; definición de “red”; activa post-jubilación)
              → origen C → pregunta a CCH
```
