# Entregables

Esta carpeta queda reservada para los consolidadores finales del trabajo de la CTA.

## Sugerido Antes Del Cierre

- resumen final de casos evaluados,
- version consolidada de dictamenes aprobados por comite,
- listado de casos con observaciones o revision adicional,
- y cualquier exportacion final preparada para SPI o para la proforma institucional.

## Regla Practica

- Mantener aqui solo resultados cerrados o casi cerrados.
- No usar esta carpeta para notas de trabajo intermedias.
