# Entregables

Esta carpeta queda reservada para materiales consolidados, listos para circular dentro de la `CTA`, la `CCH` o la instancia administrativa que corresponda.

## Contenido esperado

- resumen final del lote evaluado,
- version consolidada de dictamenes aprobados por comite,
- listado de casos con observaciones o validacion adicional,
- y cualquier exportacion final preparada para `SPI` o para proforma institucional.

## Regla practica

- Mantener aqui solo resultados cerrados o casi cerrados.
- No usar esta carpeta para notas intermedias ni para borradores de trabajo analitico.
- Si se incorpora un consolidado final, debe poder leerse sin depender de explicaciones orales externas.
